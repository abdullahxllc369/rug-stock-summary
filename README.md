# Rug stock summary

Group in-stock rugs by design, width and length. The CSV records dimensions in metres, whole-piece quantities and a rate per square metre. Use one currency throughout the file.

## Usage

Run with Python 3.8 or later from the project directory.

```sh
python stock.py sample.csv
```

The sample totals 3 rugs, 18 square metres and a value of 492.00.
